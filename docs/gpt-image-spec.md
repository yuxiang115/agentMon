# 用 GPT（或其他 AI）生成 agentMon 宠物精灵图

给 GPT/DALL-E/即梦等生成一张**规格说明**，它产出若干张 PNG，你用一条命令变成宠物包。每个状态可以有你想要的任意帧数（帧多 = 动画丰富），不再是单张图定住。

## 一、需要哪些图片

按**活动 × 帧数**准备，文件名固定为 `活动名+编号.png`（只有 `idle` 是必需的，缺的活动自动用 idle 循环兜底）：

| 文件名 | 宠物在干什么 | 建议帧数 |
| --- | --- | --- |
| `idle1.png` `idle2.png` `idle3.png` `idle4.png` | 待机/走路（agent 空闲） | **4**（必须至少 1 张） |
| `think1.png` `think2.png` | 思考（模型生成中） | 2 |
| `search1.png` `search2.png` | 读代码/搜索 | 2 |
| `code1.png` `code2.png` `code3.png` | 写代码（两帧以上交替=敲打感） | 3-4 |
| `test1.png` `test2.png` | 跑测试 | 2 |
| `happy1.png` `happy2.png` | 测试通过/任务完成（庆祝） | 2 |
| `sad1.png` `sad2.png` | 测试失败/被纠正 | 2 |
| `sleep1.png` `sleep2.png` | 会话结束睡觉 | 2 |

推荐全套 **20 张左右**。全部放进一个文件夹（比如 `my-agumon/`）。

## 二、给 GPT 的提示词（直接粘贴，替换角色描述）

```
请为我生成一套像素风游戏角色的精灵图（sprite sheet 的拆分单图），
角色是：【在这里描述你的角色，例如：一只橙色的小恐龙，圆脸、爪子、
头顶三根毛】。要求：

1. 像素艺术风格，16x16 像素网格的放大版（图像可以任意大，但视觉上
   必须是清晰的像素块，不要抗锯齿、不要渐变、不要阴影）。
2. 每张图纯白色背景（不要透明，不要场景）。
3. 角色全身居中，占画面约 80%，所有图里角色的比例、位置、大小
   完全一致，只有姿势不同。
4. 剪影清晰、轮廓连贯（最终会缩到 16x16 并二值化，细节会丢失，
   轮廓最重要）。
5. 请按下列文件名逐张生成：
   idle1 idle2 idle3 idle4（待机呼吸/左右看，轻微差异即可）
   think1 think2（低头沉思/挠头）
   search1 search2（举放大镜/张望）
   code1 code2 code3（打字，手部位置不同）
   test1 test2（握拳/挥拳，战斗预备）
   happy1 happy2（跳跃庆祝/举手）
   sad1 sad2（垂头/流泪）
   sleep1 sleep2（闭眼打盹/卧倒）
```

要点：**白底**（工具自动检测背景）、**同角色同比例**、**轮廓为主**。生成完手动挑掉走形的那几张即可。

## 三、一条命令变成宠物

```
npm run pack:from-image -- --img my-agumon/ --name 亚古兽 --id agumon --chain
```

- 自动按文件夹里的名字装配：`idle×4、code×3…`，缺的用 idle 兜底
- 自动缩放 16×14、二值化、贴地，和内置生物对齐
- `--chain` 自动接上 byte → 亚古兽 的进化门（攒行为进化）
- 生成结果直接写进宠物目录，Pi 里 `/reload` 或 `/pets import <生成的pack.json>` 后 `/pets use agumon`

预览效果：`npm run packs -- --dir ~/.pi/agent/agentmon/pets`，或直接 `/pets use` 后看右上角面板。

## 备注

- 彩色角色没问题：取墨按"与背景色的距离"判断，橙色亚古兽在白底上识别正常；若整张图几乎没识别出墨水，把 `--threshold` 调小（如 40）再试。
- 也支持：单张 PNG（自动派生 11 姿势的简版动画）、横向条图（`--frames 11`）、tuipet/DVPet 提取文件（`/pets import sprites.json 名字1,名字2`）。
- **版权提醒**：如果角色是数码宝贝等商业形象，图和数据只留在你自己机器上，不要提交到任何公开仓库。
